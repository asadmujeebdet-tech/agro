# Agro Shop Website (React + Node.js)

## Run locally
npm run install:all
npm run dev             # API on :5000 and website on :5173

## Edit your shop
Open server/server.js and change `shop` (name, WhatsApp number, address, hours) and `products`.
Customer questions are saved in server/enquiries.json.

## Go live
npm run build && npm start    # Node serves the built site on :5000
